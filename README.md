# Psy Protocol Killer Apps Lab · Psy 协议杀手级应用实验室

A protocol-product strategy lab exploring what new categories of internet-native applications become possible on Psy Protocol — when realms (uid-partitioned execution domains), recursive Plonky2 proofs over Goldilocks with Poseidon hashing, persistent psy-wallet identity, and a coordinator-aggregated state become product primitives rather than implementation details. Bilingual (EN / 中文), dark/light, cyber-civilization aesthetic with Space Grotesk + DM Sans + IBM Plex Mono on deep ink-black with psyverse-blue, coral, teal, gold, and magenta accents. Ten modules: a six-layer architecture diagram (apps → identity → state/realms → execution → coordinator + recursive ZK → L1 settlement) with four detail cards (realms, coordinator, recursive ZK, persistent identity); an interactive killer-app generator (7 categories × 6 audiences × 6 primitives) producing concept cards rated on viral / fit / scale / money / network; AI × Psy module with four design notes on agent-owned wallets, cross-app reputation, decentralized memory, agent-native DAOs; onchain-social module (portable graph, moderation as market, creator economy without lock-in, sovereign communities); persistent-worlds gaming module (mod-owned worlds, agent NPCs, hard-vs-soft governance); knowledge-network module (curation markets, citation receipts, civilization memory, honest limits); prediction-markets module with regulatory-honesty disclaimer; coordination module honestly mapping which firm functions protocols can replace, partially replace, and cannot replace; meme/narrative module on protocol legibility; future-internet simulator (5 archetypes × 4 levers × 6 outcomes); AI Strategist with five canned multi-paragraph responses and free-text heuristic fallback; explicit guardrails section refusing token shilling, buzzword padding, false novelty, and regulatory hand-waving.

## Stack

Plain HTML, CSS, vanilla JavaScript. No build step. Bilingual via `[data-lang]` + CSS attribute selectors. Light/dark via `[data-theme]`. Space Grotesk display, DM Sans body, IBM Plex Mono mono. All diagrams inline SVG. JS uses template literals throughout — verified with `node --check`.
